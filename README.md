# 图书馆用户洞察研究项目

一个基于用户研究方法论、软件运营视角与数据交易模拟的完整方案演示。

## 📌 项目简介

图书馆是一个**高度异质化**的公共空间：走进同一扇门的人，可能是写论文的研究者、备考的学生、休闲阅读的市民、打卡的体验者，也可能是寻求协作的团队或需要无障碍服务的特需用户。

本项目试图回答三个问题：

1. **谁在用图书馆？** —— 识别七类用户群体
2. **他们要什么？** —— 理解需求、行为与痛点
3. **我们能做什么？** —— 从软件运营者视角，把洞察转化为可执行动作

## 🔒 隐私与数据安全声明

本项目高度重视数据隐私与合规：

- **所有展示数据均为模拟数据**，不包含任何真实用户信息。
- 数据交易市场中的产品、价格、交易记录、买家均为虚构。
- 真实落地时，所有数据采集必须：
  1. 获得用户明确的**知情同意**；
  2. 经过**匿名化与聚合脱敏**处理；
  3. 通过第三方**隐私合规审计**；
  4. 明确**用途限制**，禁止二次转售或歧视性画像；
  5. 建立**有效期与销毁机制**。

> ⚠️ **请勿将任何原始数据、真实采集数据或隐私数据上传到 GitHub**。上传前需完成脱敏、聚合、合规审查，并获得相关方确认。

## 📊 数据来源说明

原型中的数据结构和分析框架参考了以下公开研究与案例：

- 武汉大学《图书情报知识》2024 年"数智时代图书馆用户需求变化研究"
- 北京大学信息管理系"基于多元服务需求的图书馆用户类型划分研究"
- 南京大学图书馆 2025 年度读者意见分析报告

**所有具体数值均为基于上述研究的合理模拟，非真实统计值。**

## 🎯 核心发现

1. 图书馆用户可大致分为 **7 类**：研究型、学习型、休闲型、体验型、情报型、合作型、特需型。
2. 高频痛点集中在：**数据库访问权限（40%）、空间噪音（27%）、占座治理（18%）**。
3. 作为**软件运营者**，你能直接撬动的杠杆有 4 类：软件功能、内容运营、流程规则、建议影响。
4. 数据洞察本身可以成为**数据资产**，通过合规交易市场流通。
